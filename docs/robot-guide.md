# Керування джерелом з програми робота

Бібліотека `robot/Cebora.arl` виконує обмін з контролером. У програмі робота достатньо підключити її і викликати функції `SET`, `SET_*` і `GET`.

## Файли

Файли копіюються на флеш-накопичувач робота в теку `Cebora`:

| Файл | Призначення |
|---|---|
| `Cebora.arl` | бібліотека: формування кадру, обмін по RS232, розбір відповіді |
| `Ctrl_via_CANopen.arl` | приклад програми: запуск чергової і основної дуги, рух, аварійні переривання |
| `Ctrl_via_CANopen_data.arl` | точки і швидкість для прикладу |

Підключення бібліотеки:

```
import "/USB/sda1/Cebora/Cebora.arl"
```

Шлях можна змінити, якщо змінити його в `import`.

## Обмін даними

Обмін виконується по перериванню, незалежно від затримок і кроку програми:

```
clock c

func void DataTransfer()
Cebora::main()
clkreset(c)
endfunc

func void main()
interrupt 0, when: clkread(c) >= 0.1, do: DataTransfer()
lin p:p1,v:v1
lin p:p2,v:v1
clkstart(c)
endfunc
```

Правила:

- Таймер `clkstart(c)` запускається після двох стартових точок руху. Система керування вимагає підтвердження на першій точці, тому якби таймер працював раніше, переривання обміну не залишали б оператору часу натиснути пуск.
- Для циклічного виконання мітку `Startcycle:` ставлять після `clkstart(c)`, а `goto Startcycle` в кінці. Інакше таймер скидається на кожному циклі.
- Однопрохідна програма виконується в режимі Single на пульті робота. В іншому режимі програма повторюється, і таймер обміну скидається.
- Якщо обмін зникає (вимкнено робот, аварійний стоп, обрив кабелю), через 3 с джерело зупиняється, всі параметри скидаються.

## Задання параметрів

Дискретні параметри:

```
Cebora::SET("RobotReady", 1)
Cebora::SET("PilotArc", 0)
```

Аналогові параметри:

| Функція | Діапазон |
|---|---|
| `Cebora::SET_WeldCurrent(i)` | 0...500 А, ціле |
| `Cebora::SET_WireHighSpd(d)` | -10.0...10.0 м/хв |
| `Cebora::SET_PLS_Ratio(i)` | 0...100 %, ціле |
| `Cebora::SET_WireLowSpd(d)` | -10.0...10.0 м/хв |
| `Cebora::SET_PlasmaGasFlow(d)` | 0.2...10.0 л/хв |
| `Cebora::SET_ShieldGasFlow(d)` | 5.0...30.0 л/хв |

Значення поза діапазоном обмежуються бібліотекою.

Щоб джерелом можна було керувати, потрібно задати `RobotReady`, `OperMode_1` і `OperMode_2`. Останні два вмикають режим TIG. Режим JOB вибирається бітами `JOB_0`...`JOB_7`.

Список дискретних параметрів збігається з таблицею прапорців у `protocol.md`.

## Вимірювання

```
print "Current = " + Cebora::GET("WeldCurrent") + ", A"
string s = Cebora::GET("WeldVoltage")
```

`GET` повертає рядок. Дискретні параметри повертаються як `"1"` і `"0"`. Аналогові: `WeldVoltage`, `WeldCurrent`, `MotorCurrent`, `WireFeedSPD`, `PlasmaGasFlw`, `ShieldGasFlw`. Дискретні: `CurrFlow`, `ProcActive`, `MainCurrent`, `CollisProtect`, `PowSourReady`, `Commun_Ready`, `ErrNumber_0`...`ErrNumber_7`, `PLS_Sync`, `PilotArc`, `StikingRem`, `WireAvailale`.

Значення можна виводити в файл:

```
print to:file,filepath:"/home/ae/USB/sda1/Cebora/mylog","Current = " + Cebora::GET("WeldCurrent") + ", A",endl
```

## Приклад запуску дуги

Повний текст у `Ctrl_via_CANopen.arl`, схема алгоритму на `algorithm-robot.svg`.

1. Задати готовність, режим TIG, струм і витрати газів. Чекати 1 с, щоб джерело сприйняло команди.
2. Увімкнути чергову дугу `PilotArc`. Щосекунди перевіряти зворотний `PilotArc`, до 5 спроб.
3. Коли чергова дуга є, увімкнути `Arc_On`. Щосекунди перевіряти `MainCurrent`, до 10 спроб.
4. Коли основний струм є, виконати рух `lin` у кінцеву точку, потім вимкнути `Arc_On` і `PilotArc`.

Між командою руху і наступною командою вставлено `waittime 0`. Без нього робот виконує одну наступну команду відразу після початку руху, а не після його завершення, і дуга вимикається на старті.

Переривання `inthandler1` (кнопка F1) і `inthandler2` (датчик зіткнення) швидко зупиняють рух, скидають команди дуги і ставлять програму на паузу.
